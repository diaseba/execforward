# Reference PNGs — histórico

PNGs originales generados con Gemini durante la fase de diseño del logo. Sirvieron como fuente para derivar las proporciones del sistema v1.2:

- `Variante_B_Horizontal_1024.png` → gap = 0.354 × cap-height, isoH = 1.98 × cap-height
- `Variante_C_Apilado_512.png` → isoH = 3.53 × cap-height, vGap = 0.456 × cap-height, wordmark weight 800

**No usar como logos en producción** — todos tienen artefactos de render (texto distorsionado en B, proporciones de isotipo ligeramente variables entre PNGs). Los SVGs canónicos en `_system/brand/EF_logo_*.svg` son la fuente de verdad.

Ver `uploads/Brandbook_ExecForward_v1.2.md` §2 para las fórmulas extraídas.
