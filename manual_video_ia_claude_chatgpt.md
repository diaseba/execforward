# Manual maestro para crear cualquier tipo de video con IA usando Claude + ChatGPT

Este documento sirve como guía base para crear videos de alta calidad partiendo desde cero contexto.

La lógica recomendada es:

1. Usar Claude para ordenar el contexto, entrevistar al usuario y construir un brief creativo completo.
2. Pasar ese brief a ChatGPT para convertirlo en concepto creativo, guion, storyboard, prompts por escena, dirección visual y plan de edición.
3. Generar el video en herramientas especializadas de video IA si corresponde.
4. Volver a ChatGPT para revisar, corregir prompts, mejorar narrativa, optimizar edición y preparar versiones finales.

---

# 1. Principio general

La mejor forma de crear un video con IA no es partir con un prompt visual, sino con un brief estratégico.

Un buen video necesita definir:

- qué objetivo cumple
- a quién le habla
- qué debe sentir o hacer la persona después de verlo
- qué mensaje debe quedar claro
- qué tipo de video conviene
- qué tono debe tener
- qué estilo visual corresponde
- dónde será publicado
- qué restricciones existen
- qué materiales están disponibles

La herramienta genera imágenes en movimiento.  
La dirección creativa hace que el video venda, explique, emocione o convenza.

# 2. Información necesaria antes de crear cualquier video

## 2.1 Objetivo del video

Primero hay que definir para qué existe el video.

Ejemplos de objetivos:

- vender un producto
- explicar una solución
- captar leads
- presentar una marca
- mostrar una propiedad
- lanzar un servicio
- educar al usuario
- generar autoridad
- mostrar una demo
- aumentar conversión en una landing
- crear contenido para redes
- convencer inversionistas
- presentar una empresa
- generar confianza
- diferenciarse de competidores

Preguntas clave:

```text
¿Cuál es el objetivo principal del video?
¿Qué debería hacer la persona después de verlo?
¿Qué debería sentir la persona después de verlo?
¿Qué idea debe recordar?
¿Qué acción concreta queremos provocar?
```

Ejemplos de acción esperada:

- agendar una llamada
- comprar
- dejar sus datos
- descargar un recurso
- solicitar una demo
- confiar en la marca
- entender el producto
- compartir el video
- seguir una cuenta
- responder un mensaje
- postular
- invertir
- visitar una landing

---

## 2.2 Audiencia

Hay que definir con precisión quién verá el video.

No basta decir “empresas”, “clientes”, “usuarios” o “personas”.

Preguntas clave:

```text
¿Quién es la audiencia?
¿Qué edad aproximada tiene?
¿Qué rol cumple?
¿Qué problema tiene?
¿Qué le preocupa?
¿Qué desea?
¿Qué objeciones tiene?
¿Qué lenguaje usa?
¿Qué nivel de sofisticación tiene?
¿Qué sabe ya del tema?
¿Qué no entiende todavía?
¿Qué le genera confianza?
¿Qué le genera rechazo?
```

Ejemplo débil:

```text
Audiencia: ejecutivos.
```

Ejemplo fuerte:

```text
Audiencia: ejecutivos senior de 40 a 60 años, actualmente en transición laboral, frustrados porque el mercado cambió, sienten urgencia por reposicionarse, pero rechazan contenido motivacional vacío. Quieren claridad, método y algo que se sienta serio.
```

---

## 2.3 Producto, servicio, idea o mensaje

Hay que entender exactamente qué se está mostrando, vendiendo o comunicando.

Preguntas clave:

```text
¿Cuál es el nombre del producto, servicio, marca o idea?
¿Qué hace?
¿Para quién es?
¿Qué problema resuelve?
¿Cómo lo resuelve?
¿Qué lo diferencia?
¿Qué promesa hace?
¿Qué no promete?
¿Qué alternativa usa hoy la audiencia?
¿Por qué esta solución es mejor?
¿Qué prueba, evidencia o respaldo existe?
```

Ejemplo:

```text
Producto: ExecForward.
Es un sistema digital descargable para ejecutivos senior en transición laboral.
Ayuda a ordenar su estrategia de búsqueda, redefinir su posicionamiento y ejecutar un plan concreto para volver al mercado.
No es coaching motivacional. Es una metodología práctica, multilingüe y accionable.
```

---

## 2.4 Tipo de video

El tipo de video debe elegirse según objetivo, canal y audiencia.

Tipos comunes:

| Tipo de video | Cuándo conviene |
|---|---|
| Hero video para landing | Cuando se quiere impactar rápido y aumentar conversión |
| Explainer video | Cuando el producto necesita explicación |
| Demo de producto | Cuando la interfaz o proceso es clave |
| Video emocional | Cuando se vende transformación, confianza o aspiración |
| Video testimonial | Cuando la prueba social es central |
| Video anuncio | Cuando se necesita performance en ads |
| Video pitch | Cuando se quiere convencer inversionistas o partners |
| Video educativo | Cuando se quiere enseñar y generar autoridad |
| Video corporativo | Cuando se quiere presentar empresa, equipo o visión |
| Video inmobiliario | Cuando se quiere vender o mostrar propiedad |
| Reel / TikTok / Short | Cuando se necesita atención rápida en redes |
| Video documental corto | Cuando se busca autoridad, profundidad o relato humano |
| Video UGC | Cuando se busca cercanía, naturalidad y performance |
| Video de onboarding | Cuando se quiere enseñar uso de producto |
| Video de lanzamiento | Cuando se quiere presentar una novedad |
| Video de caso de éxito | Cuando se quiere demostrar resultado |
| Video institucional | Cuando se quiere construir reputación |

Si no se sabe qué tipo de video conviene, hay que pedir una recomendación explícita:

```text
No sé qué tipo de video conviene. Recomiéndame el mejor formato según el objetivo, audiencia y canal.
```

## 2.5 Canal de publicación

El canal cambia radicalmente la estructura, duración, tono y formato.

Preguntas clave:

```text
¿Dónde se usará el video?
¿Será orgánico o pagado?
¿La persona verá el video con sonido o sin sonido?
¿Estará dentro de una landing, red social, presentación o campaña?
¿Será el primer contacto con la marca o parte de un proceso comercial?
```

Canales comunes:

- landing page
- home de sitio web
- LinkedIn
- Instagram Reels
- TikTok
- YouTube
- YouTube Shorts
- presentación comercial
- email marketing
- WhatsApp
- evento presencial
- pitch deck
- campaña pagada
- onboarding
- capacitación
- marketplace
- página de producto

Recomendaciones generales:

| Canal | Recomendación típica |
|---|---|
| Landing page | 20–60 segundos, claro, premium y directo |
| LinkedIn | 30–90 segundos, autoridad y credibilidad |
| Instagram / TikTok | 8–30 segundos, hook fuerte inmediato |
| YouTube | 60 segundos a varios minutos |
| Ads | Muy directo, beneficio claro, primeros 3 segundos críticos |
| Presentación comercial | Más explicativo y consultivo |
| WhatsApp | Corto, simple, liviano, entendible sin contexto |
| Home corporativa | Reputacional, sobrio, claro |
| Demo SaaS | Producto, problema, flujo y resultado |
| Pitch | Visión, problema, oportunidad y tracción |

---

## 2.6 Duración

Hay que definir duración objetivo.

Opciones comunes:

- 6 segundos
- 10 segundos
- 15 segundos
- 30 segundos
- 45 segundos
- 60 segundos
- 90 segundos
- 2 minutos
- 3–5 minutos
- más de 5 minutos

Regla general:

| Duración | Uso ideal |
|---|---|
| 6–10 s | teaser, loop, awareness |
| 15 s | anuncio corto |
| 30 s | landing, ads, redes |
| 45–60 s | explicación comercial breve |
| 90 s | explainer más completo |
| 2–3 min | pitch, demo, educación |
| 5+ min | tutorial, clase, video institucional profundo |

---

## 2.7 Formato visual

Definir relación de aspecto desde el inicio.

Formatos:

- 16:9 horizontal
- 9:16 vertical
- 1:1 cuadrado
- 4:5 feed
- versión adaptable para varios formatos

Recomendación:

| Formato | Uso |
|---|---|
| 16:9 | landing, YouTube, presentaciones |
| 9:16 | Reels, TikTok, Shorts |
| 1:1 | feed, posts |
| 4:5 | Instagram / LinkedIn feed |
| Multi-formato | campaña seria con reutilización |

# 3. Información creativa que mejora el resultado

Ejemplos:

- premium
- cercano
- humano
- tecnológico
- sobrio
- elegante
- emocional
- urgente
- inspirador
- minimalista
- cinematográfico
- educativo
- provocador
- humorístico
- institucional
- directo
- aspiracional
- confiable
- audaz
- simple
- técnico
- cálido
- serio
- disruptivo

Ejemplo:

```text

```

También es importante definir qué evitar:

```text
No quiero que parezca genérico, motivacional barato, stock footage corporativo ni publicidad exagerada.
```

# 7. Qué debe producir ChatGPT a partir del brief

Con el brief completo, ChatGPT puede entregar diferentes niveles de salida.

## Nivel 1 — Diagnóstico creativo

Incluye:

- qué tipo de video conviene
- qué duración recomiendo
- qué estructura usaría
- qué tono usaría
- qué evitaría
- qué referencias aplican
- riesgos creativos
- fortalezas y debilidades del brief

---

## Nivel 2 — Concepto del video

Incluye:

- idea central
- narrativa
- estructura
- mensaje principal
- estilo visual
- promesa
- CTA
- emoción central
- metáfora visual si aplica

---

## Nivel 3 — Guion

Incluye:

- voz en off
- textos en pantalla
- ritmo por segundo
- estructura narrativa
- CTA final
- versión corta y larga si aplica

Estructura típica:

```text
0–3s: Hook
3–10s: Problema
10–20s: Tensión
20–35s: Solución
35–45s: Beneficio
45–60s: CTA
```

---

## Nivel 4 — Storyboard

Incluye escena por escena:

- qué se ve
- qué se escucha
- qué texto aparece
- qué movimiento de cámara hay
- qué emoción debe provocar
- qué assets se necesitan
- duración de cada escena
- transición hacia la siguiente escena

---

## Nivel 5 — Prompts de producción

Incluye prompts listos para herramientas de video IA.

Cada escena debería tener su propio prompt.

Ejemplo:

```text
Scene 01 — Executive frustration
Duration: 5 seconds
Aspect ratio: 16:9
Visual style: premium cinematic realism
Camera: slow dolly-in
Lighting: soft morning light
Subject: senior executive alone at desk
Mood: controlled anxiety, not melodrama
Negative prompt: no exaggerated acting, no corporate stock footage look, no plastic skin, no fake UI
```

---

## Nivel 6 — Plan de edición

Incluye:

- orden de escenas
- ritmo de corte
- música recomendada
- uso de silencios
- transiciones
- overlays
- subtítulos
- CTA final
- versión sin audio
- versión con audio
- versión corta
- versión larga

---

## Nivel 7 — Paquete completo de producción

Incluye:

1. Diagnóstico crítico del brief
2. Concepto creativo
3. Guion
4. Storyboard
5. Shot list
6. Prompts por escena
7. Negative prompts
8. Texto en pantalla
9. Voz en off
10. Dirección musical
11. Dirección de cámara
12. Dirección de iluminación
13. Dirección de edición
14. Checklist de QA
15. Versiones por formato
16. Riesgos y mitigaciones
17. Recomendación de herramientas
18. Plan de producción

# 12. Modelo recomendado

## En Claude

Usar el modelo más potente disponible, idealmente la versión más avanzada tipo Opus.

Configurar:

- razonamiento extendido
- respuesta larga
- máxima calidad
- no resumir
- no inventar información
- marcar vacíos como [PENDIENTE]

Claude es útil para:

- ordenar mucha información
- transformar ideas desordenadas en brief
- expandir contexto
- hacer entrevistas largas
- producir documentos estructurados

---

## En ChatGPT

Usar GPT-5.5 Thinking cuando se necesite:

- estrategia
- estructura
- criterio creativo
- decisiones difíciles
- evaluar alternativas
- mejorar conversión
- detectar debilidades
- armar prompts finales
- producir storyboard
- comparar opciones
- definir dirección visual
- revisar resultados generados

Usar un modelo rápido solo para iteraciones menores como:

- cambiar tono
- acortar texto
- traducir
- reordenar escenas
- generar variantes simples

# 13. Regla de oro: no crear un video largo con un solo prompt

Para máxima calidad, dividir el video en escenas.

Ejemplo para video de 30 segundos:

| Escena | Duración | Objetivo |
|---|---:|---|
| 1 | 3 s | Hook |
| 2 | 5 s | Problema |
| 3 | 6 s | Tensión |
| 4 | 6 s | Solución |
| 5 | 6 s | Beneficio |
| 6 | 4 s | Cierre / CTA |

Cada escena debe tener su propio prompt.

Esto mejora:

- consistencia visual
- control creativo
- calidad de imagen
- control de cámara
- edición
- posibilidad de corregir solo una escena

# 14. Estructura ideal de un prompt de video IA

Un prompt fuerte debería incluir:

1. Duración
2. Formato
3. Tipo de plano
4. Sujeto principal
5. Acción
6. Lugar
7. Cámara
8. Lente
9. Iluminación
10. Color grading
11. Movimiento
12. Atmósfera
13. Estilo visual
14. Nivel de realismo
15. Texturas
16. Ritmo
17. Continuidad
18. Qué evitar

Ejemplo:

```text
Duration: 5 seconds.
Aspect ratio: 16:9.
Scene: A senior executive sits alone at a clean desk at dawn, looking at a laptop with quiet frustration.
Camera: slow dolly-in from medium-wide to medium close-up.
Lens: 35mm cinematic lens, shallow depth of field.
Lighting: soft natural morning light through large window, subtle shadows.
Mood: restrained tension, premium, human, not melodramatic.
Visual style: Apple-like cinematic realism, clean executive environment, realistic textures.
Motion: minimal, natural breathing, slight hand movement, laptop glow.
Color grade: cool neutral blues, soft contrast, premium commercial finish.
Avoid: stock footage look, fake acting, plastic skin, exaggerated sadness, cheap corporate office, unreadable UI, oversaturated colors.
```

# 15. Negative prompts generales

Usar restricciones para reducir errores típicos.

```text
Avoid:
- generic stock footage look
- exaggerated acting
- fake corporate smiles
- plastic skin
- uncanny valley
- distorted hands
- unreadable text
- fake UI gibberish
- overdramatic lighting
- excessive lens flare
- cheap motion graphics
- random logos
- wrong branding
- oversaturated colors
- low-resolution details
- unstable camera
- sudden scene changes
- inconsistent character appearance
- unrealistic physics
- incoherent environments
- mismatched lighting between shots
- random text on screen
- extra fingers
- deformed faces
- glitchy transitions
- cliché corporate handshake shots
- artificial-looking people
```

# 18. Workflow recomendado completo

Flujo recomendado:

```text
1. Definir idea básica.
2. Usar Claude para entrevistar y construir brief.
3. Pasar brief a ChatGPT.
4. ChatGPT evalúa críticamente el brief.
5. ChatGPT propone concepto creativo final.
6. ChatGPT crea guion, storyboard y prompts.
7. Generar escenas en herramienta de video IA.
8. Revisar resultados.
9. Corregir prompts.
10. Regenerar escenas débiles.
11. Editar versión final.
12. Crear versiones por canal.
13. Hacer QA final.
```

# 19. Recomendación operativa

Para cualquier video serio, seguir esta secuencia:

```text
Brief completo
→ Concepto creativo
→ Guion
→ Storyboard
→ Prompts por escena
→ Generación de escenas
→ Revisión crítica
→ Corrección de prompts
→ Edición final
→ Versión por canal
```

No partir por la herramienta.  
Partir por el objetivo, la audiencia y la emoción.
